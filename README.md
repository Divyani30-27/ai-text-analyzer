# 🤖 AI Text Analyzer

AI Text Analyzer is a Python-based web application that analyzes user-provided text and provides useful insights such as text statistics, sentiment analysis, polarity, subjectivity, and frequently used keywords.

## 🚀 Features

- 📊 Text statistics
  - Word count
  - Character count
  - Sentence count

- 😊 Sentiment Analysis
  - Positive
  - Negative
  - Neutral

- 📈 Sentiment details
  - Polarity
  - Subjectivity

- 🔑 Keyword extraction
  - Identifies frequently used words

- 🌐 Interactive web interface using Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- TextBlob
- NLTK
- Python Collections
